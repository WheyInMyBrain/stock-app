# 📊 Parallel Quantitative Analysis Core (`stock-app/analysis`)

A high-velocity, multi-threaded financial modeling and quantitative analytics engine built in Rust. This module implements a **decoupled zero-copy data broker architecture** to process the unified Parquet tables generated by the parsing engine. It executes deterministic valuations, stochastic simulations, macro state transitions, and structural credit risk models concurrently across the Rayon thread pool, writing the final projection matrices as structured JSON objects into the ticker's analysis folder.

---

## ⚡ Core Computing Pipeline

```
┌────────────────────────┐      ┌────────────────────────┐      ┌────────────────────────┐
│ Immutable Parquet Data │ ───> │  Zero-Copy Memory Cache │ ───> │ Structured JSON Matrix │
│ (../data/<TICKER>/)    │      │  (data_loader.rs Core) │      │ (../data/<TICKER>/analysis)
└────────────────────────┘      └────────────────────────┘      └────────────────────────┘

```

1. **Single-Pass Ingestion:** Loads all raw statement line items and historical shareholding timelines from disk exactly once into shared memory.
2. **Concurrent Task Grid Spawning:** Distributes 10 parallel engine tracks across separate CPU worker threads without copy overhead or disk locking bottlenecks.
3. **Automated Matrix Dumping:** Flashes the completed multi-scenario valuation models straight to disk using a generic serialization helper.

## 📂 Analytical Module Architecture

### 🧮 Valuation & Forecasting Engines

* **`dcf/` (Discounted Cash Flow):** Computes high-resolution deterministic matrix grids using variable baseline WACC and terminal perpetuity growth scenarios.
* **`epv/` (Earnings Power Value):** Unpacks normalized corporate earnings power perpetuities to isolate structural business franchise moats from basic commoditized operations.
* **`monte_carlo/`:** Samples historical statistical moments to run 10,000+ stochastic path trials via Euler-Maruyama approximations, extracting percentile risk expectations (P10/P30/P50/P70/P90).

### 📉 Multiples & Structural Risk Engines

* **`multiples/`:** Compiles comprehensive 5-stage DuPont operational matrices, Altman Z-Scores, Beneish M-Scores, Piotroski F-Scores, liquidating dissolution cash positions, and multi-tier cost elasticity shocks.
* **`markov_regime/`:** Infers hidden macroeconomic and efficiency shift patterns on a rolling basis, evaluating transition probability metrics (Expansion, Stagnation, or Structural Crunch modes).
* **`merton_bates/`:** Simulates stock price trajectory distributions and rolling trailing volatilities using a continuous jump-diffusion path-stepping module.
* **`merton_kmv/`:** Runs a non-linear 2D Newton-Raphson solver that treats public equity as a liquid call option on unobservable assets, mapping physical asset volatilities, true Distances to Default (DD), and Expected Default Frequencies (EDF).

### 🚀 Core System Infrastructure

* **`main.rs`:** The central CLI parser wrapper that reads execution arguments (`wacc`, `term_g`) and kicks off the orchestration process.
* **`runner.rs`:** The multi-threaded control center that coordinates thread scopes, handles exchange-listing guards, and maps analytical tracks.
* **`data_loader.rs`:** The central in-memory warehouse that cleans and pivots raw Parquet tokens, matching chronological statement periods down to March-Annual configurations.
* **`helper.rs`:** A optimized file-dump utility that filters blank records and handles pretty JSON writing on a background thread.
